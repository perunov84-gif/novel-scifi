# Agents

This directory will hold specialized agent contracts for the AI Book Framework.

## Sprint status

Sprint 1 does **not** ship role files yet. Upcoming sprints will add contracts such as:

- `architect.md`
- `research.md`
- `outline.md`
- `writer.md`
- `review.md`

Until those files exist, operate with the stage discipline in [`../WORKFLOW.md`](../WORKFLOW.md) and [`../USER_GUIDE.md`](../USER_GUIDE.md), and keep outputs in durable markdown.

## What an agent file must define

When agent files arrive, each contract should specify mission, inputs, outputs, acceptance criteria, forbidden behaviors, handoff expectations, and escalation rules. See Architecture §8 in [`../docs/specifications/001_ARCHITECTURE.md`](../docs/specifications/001_ARCHITECTURE.md).
