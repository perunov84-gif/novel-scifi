# Workflow

Canonical stage order for novel production in the AI Book Framework:

```text
Book Brief → Architect → Research → Outline → Writer → Review → Revision
```

## Stage intents

| Stage | Intent |
| --- | --- |
| Book Brief | Lock premise, audience, tone, themes, POV policy, and hard constraints |
| Architect | Design acts, major turns, escalation, and thematic spine |
| Research | Produce grounding constraints the story must respect |
| Outline | Define scene contracts: goal, conflict, turn, payoff |
| Writer | Draft prose under outline, voice, and canon constraints |
| Review | Adjudicate continuity, structure, character, pacing, prose, and theme |
| Revision | Repair defects; update outline/canon when structure or facts change |

## Operating rules

- Do not skip upstream approvals for convenience.
- Write stage outputs into repository files.
- Treat review as a gate, not a compliment pass.
- Human accepts brief, architecture, outline spans, and final chapter status.
