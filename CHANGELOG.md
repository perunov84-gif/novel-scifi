# Changelog

All notable changes to the AI Book Framework are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).  
This project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html) for framework releases.

## [0.1.0] — 2026-08-13

### Added

- Professional root operator documentation: `README.md`, `QUICK_START.md`, `USER_GUIDE.md`
- Canonical specifications:
  - `docs/specifications/000_PROJECT_VISION.md`
  - `docs/specifications/001_ARCHITECTURE.md`
- `CHANGELOG.md` (this file)
- `LICENSE` (MIT)
- Directory scaffolding with operator READMEs:
  - `docs/guides/`
  - `docs/decisions/`
  - `prompts/` (including role subdirectories)
  - `templates/`
  - `examples/`
  - `modules/`
  - `tools/`
- Expanded `.gitignore` for OS junk, editor metadata, secrets, and local tool caches

### Notes

- Sprint 1 delivers the framework **kernel documentation and repository shape**.
- Specialized agent contracts, Cursor rule packs, book templates, and novel content files are intentionally deferred to later sprints.
