# Guides

Practical how-to documents for operators of the AI Book Framework.

## Purpose

Guides explain *how to work* with the system in plain language: continuity habits, revision loops, research hygiene, and similar craft-operational topics.

## Authority

Guides are **explanatory**, not supreme law. If a guide conflicts with a file in [`../specifications/`](../specifications/), the specification wins until the spec is formally amended.

## What belongs here

- Authoring practice guides tied to framework stages
- Continuity and revision playbooks for humans
- Onboarding deep-dives that are too long for `USER_GUIDE.md`

## What does not belong here

- Normative contracts (those go in `docs/specifications/`)
- Live novel canon or chapter drafts (those go under `book/`)
- One-off chat transcripts
